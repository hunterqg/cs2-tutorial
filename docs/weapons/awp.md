# AWP 架点与瞬狙教学

## 一句话答案

AWP 是 CS2 中**一枪毙命的狙击步枪**（胸部以上必杀）。核心打法是**预瞄 + 架点 + 瞬狙**：预瞄常见过点、架好等待敌人出现、瞬狙结合预瞄打快速甩枪。AWP 的关键不在于开枪速度，而在于**站位选择和信息判断**。

## 弹道图解

```
开镜后准星状态：

站立：   ○ ← 精准
蹲姿：   ○ ← 同样精准
移动：   ✕ ← 绝对不准（必打偏！）

开镜→开枪时间序列：
[架点] → 敌人出现 → 预瞄到位 → 开枪 (杀敌)
                              ↓
[架点] → 敌人出现 → 预瞄偏差 → 甩枪修正 → 开枪 
```

AWP 只有"准"和"不准"两种状态：静止开镜时 100% 精准，任何移动都导致子弹随机偏离。

## 分距离策略

### 任意距离（通用原则）

AWP 不区分远近：**只要在视距内，胸部以上必杀。**

- **架点节奏**：架 3-5 秒换一个角度，不要死盯一个点
- **Jiggle Peek**：左右晃身探信息，看到人退回掩体再开镜预瞄
- **手枪副武器**：近身被贴时切手枪或刀快速跑位

### 常用架点技巧

**预开镜架点：**
- 预瞄敌人可能出现的位置（门缝、拐角、箱子缝隙）
- 准星保持在爆头线高度
- 听到脚步声时手指准备在左键上

**瞬狙：**
- 不开镜先对准目标 → 右键+左键几乎同时按
- 适合中近距离遭遇战
- 练习要领：准星在屏幕中心感

**甩狙：**
- 开镜后准星不在目标上，快速甩过去同时开枪
- 适合多个架点之间的快速切换
- 需要大量肌肉记忆

## 常见误区

- ❌ **开镜状态下移动**：AWP 开镜移动时子弹完全随机。开镜后必须站定或蹲定。
- ❌ **过度追求甩狙速度**：稳定击杀 > 快但偏的甩狙。先练好架点预判，再练甩狙。
- ❌ **不切枪换弹**：AWP 只有 5/10 发子弹。打 1 发后不切手枪/刀换弹是新手常见错误——切枪比换弹快 0.5 秒。
- ❌ **站同一个架点不换位**：打 1 枪就必须换位置。对面会报点，接着就是闪光弹和 rush。
- ❌ **AWP 去打远距离移动目标**：不要跟远距离左右晃身的步枪对枪，除非你有十足把握。

## 练习方法

- **死斗模式（AWP only）**：强迫自己只用 AWP，练习快速开镜→击杀→切枪→换位
- **练习赛**：练预开镜架点和 Jiggle Peek 节奏
- **创意工坊**：`AWP Training` 或 `Quick Peek Practice`
- **训练目标**：
  - 第 1 周：练习 100 次架点击杀（预判位）
  - 第 2 周：练习瞬狙（不开镜先瞄准）
  - 第 3 周：实战中强迫每枪必换位
